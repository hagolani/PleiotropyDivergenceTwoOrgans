# Pleiotropy and modularity in the evolution of interacting teeth

Code and data for:

Pascal Hagolani,Marie Sémon, Guillaume Beslon, Sophie Pantalacci. Pleiotropy promotes divergence when simulating the development and evolution of two interacting organs. *<JOURNAL>*. DOI: <DOI>

We couple a developmental model of tooth morphogenesis to an evolutionary
algorithm in which upper and lower teeth evolve under selection for occlusion.
The developmental parameters of each tooth are encoded by a constitutive part,
shared between the two teeth (with pleiotropy) or tooth-specific (without
pleiotropy), and by tooth-specific Hox elements. The analysis scripts in this
repository reproduce all figures and supplementary tables of the article.

## Repository structure

```
analysis/     R scripts, one per figure group, plus the table builder
data/raw/     simulation output (download from Zenodo, see data/raw/README.md)
data/processed/  files read by the analysis scripts (download from Zenodo, see data/raw/README.md)
simulation/   developmental model and evolutionary simulations
output/       created by the scripts: figures, statistics, tables
```

## Reproducing the figures and tables

Requirements: R (≥ 4.1) and Python 3.

```bash
# 1. R packages (exact versions are recorded in renv.lock)
Rscript -e 'install.packages("renv"); renv::restore()'

# 2. All figures and statistics -> output/<script name>/
Rscript analysis/run_all.R

# 3. Supplementary tables -> output/tables/supplementary_tables.xlsx
pip install -r requirements.txt
python analysis/make_tables.py
```

Scripts that need the raw simulation output (`sfig_raw_analysis.R`,
`sfig_S2_analysis.R`) are skipped if `data/raw/` is empty. Each script can
also be run on its own, e.g. `Rscript analysis/fig4_analysis.R`.
